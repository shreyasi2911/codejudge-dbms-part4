# Part 4 — Transactions, Safe Changes & DB Reliability

## Objective
This part demonstrates safe database modification practices using UPDATE, DELETE, transactions, rollback, savepoints, and ACID concepts.

## Safety Measures Used
- Worked on a copied database
- Verified rows using SELECT before modifications
- Used transactions for testing
- Used WHERE clauses carefully
- Used ROLLBACK during validation
